# Python 基础

这一阶段从 Python 最小语法开始，逐步覆盖容器、函数、作用域、面向对象、异常、模块、包、文件操作、正则和基础数据结构。

## 学习单元

- `00-pycharm-entry-demo/`：PyCharm 生成的入口脚本，理解 `if __name__ == "__main__"`。
- `01-syntax-variables-operators/`：变量、类型、输入输出、格式化、运算符和入门作业。
- `02-control-flow-functions-lists/`：循环、break、函数参数、模块导入、列表和作用域。
- `03-containers-memory-functions/`：元组、字典、集合、字符串、切片、内存与返回值。
- `04-recursion-oop-intro/`：递归、可变参数、默认参数和 OOP 入门。
- `05-oop-exceptions-patterns/`：封装、继承、多态、单例、异常捕获与传播。
- `06-modules-packages-file-io/`：模块、包、导入冲突、自定义包和文件/目录操作。
- `07-data-structures-sorting/`：二叉树、排序算法、`sort` 与 `sorted`。
- `08-copy-regex-modules/`：类型判断、深浅拷贝、正则表达式和模块导入。

## 主线

重点不是写大型项目，而是建立后续机器学习实验所需的 Python 阅读和调试能力。
