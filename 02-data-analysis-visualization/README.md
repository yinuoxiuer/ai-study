# 数据分析与可视化

这一阶段把 Python 基础转向数据探索：先熟悉 Jupyter 与 Matplotlib，再学习 NumPy 的数组计算和 Pandas 的表格分析。

## 学习单元

- `01-jupyter-matplotlib-intro/`：Notebook 基础和 Matplotlib 折线图。
- `02-numpy-matplotlib-basics/`：NumPy 创建、切片、广播、统计，以及常见图表。
- `03-numpy-pandas-eda/`：NumPy 读 CSV、Pandas Series/DataFrame、缺失值、排序、YouTube/IMDB 数据分析。
- `04-pandas-time-series-911/`：911 报警数据项目，练习时间索引、重采样、分组统计和可视化。

## 主线

这一阶段的目标是能把原始 CSV 读进来、清洗、分组、可视化，并能解释图表反映的问题。
