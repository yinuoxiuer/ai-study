# 传统机器学习

这一阶段以 scikit-learn 为主，从特征工程进入分类、回归、聚类、异常检测和集成学习。

## 学习单元

- `01-feature-engineering-classification/`：字典特征、文本特征、中文分词、标准化、缺失值和分类算法入口。
- `02-knn-bayes-decision-tree/`：KNN、朴素贝叶斯、决策树和树结构可视化。
- `03-regression-clustering-gradient-descent/`：线性/逻辑回归、梯度下降、聚类算法。
- `04-ensemble-anomaly-dbscan/`：DBSCAN、IQR/Z-score、Isolation Forest、Voting、Bagging、Random Forest、Boosting。

## 主线

重点是理解机器学习项目的基本形态：数据预处理、特征变换、模型训练、评估、调参和结果可视化。
